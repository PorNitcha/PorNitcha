### Lesson Learned (07-Sep-2026 16:40)
1. **การอ่าน xlsx ที่มี sheet ซ่อนใหญ่ = ลอตเตอรี่ ไม่ใช่ deterministic** — mtime เท่าเดิมเป๊ะกับรอบ 15:10 (ที่อ่านได้ 2,357 บรรทัดแล้วตัด) แต่รอบนี้ได้ **4,434 บรรทัดครบ** ⇒ read budget แปรผันตามรอบ ไม่ใช่ตามไฟล์ · **สรุปกฎใหม่: ถ้ารอบก่อนอ่านไม่ได้ ให้ลองใหม่รอบถัดไป 1 ครั้ง (ไม่ retry ในรอบเดียวกัน)** — คุ้มกว่าการยกเป็นงานค้างถาวร
2. **ผลลัพธ์เกิน token limit ให้ใช้ไฟล์ที่ระบบเซฟ + bash เสมอ** — `read_resource` เด้ง error พร้อม path · หา path ด้วย `find ... -name "mcp-*<id>.txt"` แล้ว grep `'^## Sheet:'` เพื่อ locate ก่อน แล้วค่อย parse เฉพาะ block · **ห้าม cat/awk ทั้งไฟล์**
3. **`/tmp` ใน sandbox อาจมีไฟล์ค้างจาก session อื่นและเขียนทับไม่ได้** — รอบนี้ `/tmp/parse_aug.py` เป็นของ session `quirky-compassionate-keller` → `Permission denied` แต่ **python ยังรัน script เก่าทับ** ทำให้ผลลัพธ์หลอก ⇒ **ให้เขียน script ลง `/sessions/<id>/work/` เท่าน้อยและตั้งชื่อไม่ซ้ำ อย่าใช้ `/tmp`**
4. **array ข้อมูลใน dashboard อยู่ใน object `const plants = {...}` ไม่ใช่ const แยกตัว** — regex หา `const <NAME> = [...]` จะได้ 0 จุดและ **verify ผ่านแบบหลอก** · วิธีที่ถูก: ตัด `const dates` + `plants` object ด้วยการนับ brace แล้วให้ **node print JSON** ออกมาเทียบ ⇒ ได้ 900 จุดจริง · **ครั้งหน้าใช้วิธี node-extract นี้เลย**
5. **`len(html_string)` เป็นจำนวนอักขระ ไม่ใช่ไบต์** — 27,254 chars = 33,489 bytes เพราะภาษาไทย 3 ไบต์/ตัว · **อย่าตกใจว่าไฟล์หายไป 6 KB** ให้เทียบ bytes กับ bytes เท่านั้น
