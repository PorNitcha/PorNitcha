# Short-Term Memory — เรื่องค้าง / ยังไม่ Confirm

เก็บทุกเรื่องที่คุยค้างไว้ ยังไม่จบ ยังไม่ confirm ต้องคุยต่อในวันถัดไป

**กฎ:** ก่อนเริ่มงานเรื่องใด ให้เช็คไฟล์นี้ก่อนเสมอว่ามีเรื่องค้างที่เกี่ยวข้องหรือไม่
เมื่อเรื่องไหน confirm แล้ว → ย้ายไป `mid-term.md` (ใช้ได้ ~1 ปี) หรือ `long-term.md` (ใช้ได้ 5 ปี+ / branding-CI/ข้อมูลบริษัท) แล้ว**ลบออกจากที่นี่ทันที**

## ฟอร์แมต entry
```
### [วันที่เริ่มคุย] — [หัวข้อ]
- สถานะ: รอ confirm / รอข้อมูลเพิ่ม / รอการตัดสินใจจาก Por
- รายละเอียด/context:
- เกี่ยวข้องกับ: Por / น้องพยาก / น้องทุน / น้องโอกาส
- ต้องทำอะไรต่อ (next step):
- ติดตามภายในวันที่ (follow-up date):
```
