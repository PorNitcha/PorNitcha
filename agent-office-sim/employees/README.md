# employees/ — การ์ดพนักงาน AI ของคุณ

โฟลเดอร์นี้คือ "แฟ้มพนักงาน" ให้คนอ่านและให้ AI อ่าน

กติกาสำคัญ:

1. พนักงาน 1 คน = ไฟล์ `.md` 1 ไฟล์ (คัดลอกจาก `_TEMPLATE.md`)
2. ตัวที่ทำให้พนักงานปรากฏบนจอคือ `data/employees.js` — การ์ด `.md` เป็นต้นฉบับสำหรับคิด/แก้
3. วิธีที่ง่ายที่สุด: แก้/เพิ่มการ์ด `.md` แล้วส่ง prompt ใน `00_COPY_THIS_PROMPT_TO_AGENT.md` ให้ AI ของคุณ (Claude / Codex / ChatGPT) sync ลง `data/employees.js` ให้อัตโนมัติ

ห้ามใส่ข้อมูลจริงที่อ่อนไหว เช่น เบอร์ลูกค้า รหัสผ่าน API key ลงในการ์ดพนักงาน
