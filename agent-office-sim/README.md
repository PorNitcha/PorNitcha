# 🏢 Agent Office Sim — ออฟฟิศพนักงาน AI ของคุณเอง

**โหลดปุ๊บ ใช้ได้เลย** — เปิดไฟล์เดียว เห็นออฟฟิศทั้งบริษัท: พนักงาน AI แต่ละแผนกนั่งทำงาน เดินไปหากัน และคุยกันตามบทบาทของตัวเอง

ธีมตั้งต้น: **Thai Wah Virtual Office** (สีแบรนด์ deep violet + cyan) — เปลี่ยนเป็นบริษัทของคุณเองได้ในไฟล์เดียว

## 🚀 เริ่มใช้ใน 10 วินาที

1. ดาวน์โหลด / clone repo นี้
2. ดับเบิลคลิก `index.html` (เปิดใน Chrome / Edge / Safari ได้เลย ไม่ต้องติดตั้งอะไร)
3. เสร็จแล้ว! พนักงาน 8 คนจะเริ่มทำงาน เดินคุยกันเอง

> ทางเลือก (ถ้าอยากเปิดผ่าน local server):
>
> ```bash
> python3 -m http.server 8000
> ```
>
> แล้วเปิด `http://localhost:8000`

## 🎮 เล่นอะไรได้บ้าง

- **ดูพนักงานทำงาน** — แต่ละคนพูดถึงงานของแผนกตัวเอง (bubble เหนือหัว)
- **ดูพนักงานเดินคุยกัน** — ระบบจับคู่ให้เดินไปเจอกันที่ห้องประชุม/Pantry แล้วคุยกันตามบริบทของสองแผนก เช่น การตลาด×ขาย คุยเรื่อง lead, ขาย×โรงงาน คุยเรื่องคิวส่งของ
- **คลิกที่พนักงาน** — เปิดการ์ดโปรไฟล์: ตำแหน่ง บุคลิก แผนก
- **⏸ พัก / ⚡ x2** — หยุดฉากหรือเร่งความเร็ว

## 📁 โครงสร้าง repo

```text
agent-office-sim/
├── index.html                 ← เปิดไฟล์นี้
├── css/office.css             ← หน้าตา/ธีม
├── js/                        ← ระบบ (world / agents / dialogue / main)
├── data/
│   ├── office-config.js       ← ชื่อบริษัท สีแบรนด์ แผนก/ห้อง  ★ แก้ที่นี่
│   ├── employees.js           ← พนักงาน AI ที่ปรากฏบนจอ        ★ แก้ที่นี่
│   └── dialogues.js           ← บทคุยระหว่างแผนก               ★ แก้ที่นี่
├── employees/                 ← การ์ดพนักงาน .md (ต้นฉบับให้คน+AI อ่าน)
├── assets/backgrounds/        ← วางภาพพื้นหลังของคุณ (ถ้าต้องการ)
├── docs/CUSTOMIZE.md          ← คู่มือปรับแต่งละเอียด
└── 00_COPY_THIS_PROMPT_TO_AGENT.md  ← prompt ให้ AI ช่วยเพิ่มพนักงาน
```

## ✨ ทำให้เป็นบริษัทของคุณ (3 ขั้น)

1. **เปลี่ยนบริษัท/สี/แผนก** → แก้ `data/office-config.js` (ชื่อ, theme, rooms)
2. **เพิ่ม/แก้พนักงาน** → สร้างการ์ดใน `employees/` (คัดลอก `_TEMPLATE.md`) แล้วให้ AI ของคุณ sync ลง `data/employees.js` ด้วย prompt ใน `00_COPY_THIS_PROMPT_TO_AGENT.md` — หรือแก้ `data/employees.js` เองตรง ๆ ก็ได้
3. **เพิ่มบทสนทนา** → เติม topic ใน `data/dialogues.js` ตามคู่แผนกที่อยากให้คุยกัน

รายละเอียดทั้งหมด: [docs/CUSTOMIZE.md](docs/CUSTOMIZE.md)

## 🖼 ภาพพื้นหลัง

ค่าเริ่มต้นใช้ภาพ **Thai Wah office** ที่ให้มาใน `assets/backgrounds/thaiwah-office.png` (พร้อมใช้ทันที) — พิกัดห้องใน config จูนให้ตรงกับภาพนี้แล้ว

อยากใช้ภาพของตัวเอง: gen ภาพใหม่ (มี prompt ตัวอย่างใน [assets/backgrounds/README.md](assets/backgrounds/README.md)) วางไฟล์ใน `assets/backgrounds/` แล้วแก้ path ใน `data/office-config.js` — หรือสลับกลับเป็นผังวาดด้วยโค้ดด้วย `background.mode: 'builtin'` ก็ได้

## 🧭 หลักคิดของ Agent Office

- พนักงาน AI 1 คน = 1 บทบาท + ขอบเขตชัดเจน (ดูหัวข้อ "ขอบเขต" ในการ์ดพนักงาน)
- งานที่มีผลจริงกับภายนอก (โพสต์จริง จ่ายเงินจริง ส่งลูกค้าจริง) ต้องมีมนุษย์อนุมัติเสมอ
- repo นี้เป็น **ออฟฟิศจำลองเพื่อเรียนรู้** — ไม่เชื่อมต่อระบบจริงใด ๆ ไม่มี API key ไม่มีข้อมูลลูกค้า

## ❓ FAQ

**เปิดแล้วจอขาว?** — เช็คว่าโฟลเดอร์ครบ (js/, data/, css/ ต้องอยู่ข้าง index.html) และเปิดด้วยเบราว์เซอร์รุ่นใหม่

**พนักงานไม่เดิน?** — ถ้าเครื่องเปิดโหมด "ลดการเคลื่อนไหว" (reduced motion) พนักงานจะคุยกันจากโต๊ะแทน มีข้อความแจ้งใต้แถบบน

**เพิ่มพนักงานได้กี่คน?** — เพิ่มได้เรื่อย ๆ แนะนำห้องละไม่เกิน 2-3 คนจะดูสวยสุด (เพิ่มห้องได้ใน config)
