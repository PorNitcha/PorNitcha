# คู่มือปรับแต่ง Agent Office Sim

ทุกอย่างเป็นไฟล์ static — แก้ไฟล์ → refresh เบราว์เซอร์ → เห็นผลทันที

## 1. เปลี่ยนชื่อบริษัท + สีแบรนด์

แก้ `data/office-config.js`:

```js
companyName: 'บริษัทของคุณ',
officeName: 'Your Virtual Office',
theme: {
  primary: '#22155A',  // สีหลักของแบรนด์
  accent:  '#00AEEF',  // สีรอง/เน้น
  ...
},
```

## 2. เพิ่ม/แก้แผนก (ห้อง)

ห้องทั้งหมดอยู่ใน `rooms` ของ `data/office-config.js` — พิกัดอยู่ในระบบ 1600×900:

```js
{ id: 'rnd', name: 'R&D & นวัตกรรม', icon: '🔬', type: 'room', x: 60, y: 540, w: 340, h: 290 },
```

- `id` — ใช้อ้างใน `dept` ของพนักงาน และใน key ของบทสนทนา
- `type: 'room'` = ห้องทำงาน (มีโต๊ะ 2 ตัว) / `type: 'common'` = พื้นที่ส่วนกลางที่พนักงานเดินไปเจอกัน
- อย่าวางห้องทับทางเดินกลาง (แถบ y ระหว่าง 350–520)

## 3. เพิ่มพนักงาน AI

วิธีแนะนำ: สร้างการ์ดใน `employees/` แล้วให้ AI sync ตาม `00_COPY_THIS_PROMPT_TO_AGENT.md`

วิธีตรง: เพิ่ม object ใน `data/employees.js`:

```js
{
  id: 'somchai',
  name: 'พี่สมชาย',
  role: 'R&D Lead',
  avatar: '🧑🏻‍🔬',
  dept: 'rnd',            // ต้องตรงกับ room id
  color: '#3aa76d',
  personality: 'ชอบทดลอง ไม่กลัวพัง เรียนรู้เร็ว',
  lines: ['สูตรใหม่ทดสอบรอบ 3 แล้วครับ 🧪', 'ขอตัวอย่างวัตถุดิบเพิ่มหน่อยครับ'],
},
```

## 4. เพิ่มบทสนทนาระหว่างแผนก

แก้ `data/dialogues.js` — key คือคู่แผนก **เรียงตามตัวอักษร** คั่นด้วย `|`:

```js
'rnd|supply': [
  ['สูตรใหม่พร้อมทดลองผลิตแล้วครับ', 'ขอ spec วัตถุดิบก่อนนะคะ เดี๋ยวจองไลน์ผลิตให้', 'ส่งให้เลยครับ 🙌'],
],
```

- แต่ละ topic เป็น array ของประโยค สลับผู้พูดไปมา (คนแรก = ผู้เริ่มคุย)
- ถ้าคู่แผนกไหนไม่มี topic ระบบจะใช้ชุด `default` (คุยเรื่องทั่วไป)
- คู่แผนกเดียวกันก็ได้ เช่น `'supply|supply'` สำหรับคนในแผนกเดียวกัน

## 5. ใช้ภาพพื้นหลังของตัวเอง

ดู `assets/backgrounds/README.md` — สรุปสั้น ๆ:

1. วางไฟล์ภาพ (แนะนำ 1600×900) ใน `assets/backgrounds/`
2. แก้ `data/office-config.js`:

```js
background: { mode: 'image', image: 'assets/backgrounds/thaiwah-office.png' },
```

3. ผังห้อง (rooms) ยังใช้กำหนดว่าใครนั่งตรงไหน/เดินไปไหน — ปรับพิกัดห้องให้ตรงกับภาพของคุณ

## 6. ปรับพฤติกรรมพนักงาน

ค่าคงที่อยู่หัวไฟล์ `js/agents.js`:

- `WALK_SPEED` — ความเร็วเดิน (px/วินาที)
- `BUBBLE_MS` — เวลาที่ bubble แต่ละประโยคค้างบนจอ
- `CHAT_COOLDOWN_MS` — พักนานแค่ไหนก่อนคุยรอบใหม่

## Troubleshooting

| อาการ | สาเหตุที่พบบ่อย |
| --- | --- |
| จอขาว | เปิดไฟล์เดี่ยวโดยไม่มีโฟลเดอร์ js/data/css อยู่ข้างกัน |
| พนักงานไม่ขึ้น | `dept` ไม่ตรงกับ room id / ลืม comma ใน employees.js (ดู Console F12) |
| ไม่เดิน | เครื่องเปิด reduced motion — เป็นพฤติกรรมตั้งใจ พนักงานคุยจากโต๊ะแทน |
| ภาพพื้นหลังไม่ขึ้น | path ผิด หรือชื่อไฟล์ไม่ตรง ตัวพิมพ์เล็ก-ใหญ่ต้องเป๊ะ |
