HVA_build — scripts that generate the HVA tracker, risk file and quadrant page (FP&A, Oct 2026)
Run from this folder (inputs are relative):
  python prof1.py        -> data_actual.csv  (re-export when TDC Profitability_Act ... _AddPPA.xlsx changes; edit the path inside)
  python tier1.py        -> tiers.json       (customer x reaction history, product GP = NS - AF - AG - AH)
  python ap_monthly.py   -> ap27_quarterly.csv (from topline_final_copy.xlsx = copy of Top Line HVA ..._Final.xlsx; refresh the copy when the AP changes)
  python tier10.py       -> HVA GP tier tracker 2027 vN.xlsx   (edit OUT; copy the previous version first: the script opens OUT and replaces sheets)
  python risk6.py        -> HVA 2027 Q1-Q2 volume delivery risk vN.xlsx (edit OUT)
  python quad_v2.py      -> quad2.json for the quadrant artifact (quadrant_template.html + inline JSON)
Both tier10.py and risk6.py call hva_format.apply() just before saving: it re-applies Por's manual format adjustments stored in ../memory/hva-format-profile.json
(zoom, column widths, renamed headers, collapsed column groups, highlighted header, actual/forecast border). Add new adjustments there, not in the builders.
Coloured customer names: ../memory/hva-coloured-customers.json.
